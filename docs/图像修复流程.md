# 图像修复流程（Image Inpainting Playbook）

> 沉淀自 2026-10-24 HexGL title.png 署名文字处理（九轮迭代，提交链 4cb178b → 500625b）。
> 适用场景：去除图片中的文字/水印/logo 并让背景自然连续，不留鬼影、不留涂抹感。

## 通用流程（四阶段）

### 阶段一 · 判定：什么是『要删的东西』

1. **用空洞定义判定，不用颜色阈值**：
   - 空洞 = 原图该像素不透明（alpha>15）但清理版该像素透明
   - 颜色阈值（如 R-B>10 判橙色）会误伤画面中同色系 artwork（本次误伤船体橙色涂装 2110px）
2. 空洞内再分类：
   - 文字色（高对比/高亮/彩色）→ 需重建
   - 阴影/描边残迹（颜色偏离背景且 alpha 中等）→ 需重建
   - 背景色像素 → 直接保留原图（背景本来就在那里）

### 阶段二 · 取色：参考像素必须校验

- **取色参考像素必须校验 alpha 强度**：每行/每列第一个不透明像素可能是光晕最外缘（alpha 仅 16），复制后几乎不可见——『填了但看不见』会被误判为『没填』
- 参考像素应满足：非空洞 + alpha 足够（如 >60）+ 颜色接近背景基色

### 阶段三 · 重建：按背景材质选方法

| 背景材质 | 方法 | 原因 |
|---|---|---|
| 平滑渐变（毛玻璃/光晕/天空） | **alpha 扩散求解**：以周围背景像素 alpha 为边界条件，Jacobi 迭代至收敛；RGB 取背景基色 | 唯一能保证与周围完全连续的方法 |
| 纹理背景（草地/墙面） | 邻域扩散填充（多轮迭代） | 纹理有随机性，扩散可接受 |
| 复杂结构 | 分块处理 + 人工校验 | 无通用解 |

- 毛玻璃特性：RGB 恒定、alpha 平滑渐变 → 只需解 alpha 一个通道

### 阶段四 · 验证：颜色与 alpha 双维度

1. **鬼影检查**：统计『原图不透明但结果透明』的像素数，必须为 0
2. **条带指标**：统计相邻像素 alpha 跳变 >30 的边缘数（修复区域内），必须为 0
3. **ASCII 图只看 alpha 维度**，看不出颜色不均——必须配合上述两个数值指标
4. 肉眼验收：线上实际查看（用户最终标准）

## 反模式清单（踩过的坑）

| 反模式 | 后果 | 案例 |
|---|---|---|
| 颜色阈值判定文字 | 误伤同色系 artwork | 船体橙色涂装被误替换 |
| 取色不校验 alpha | 填了但看不见，误判为没填 | 光晕边缘 alpha=16 整行复制 |
| 同行线性插值 | 端点为透明像素时产生透明鬼影 | 毛玻璃上出现透明文字形状 |
| 整像素复制参考色 | 硬边界色块，涂抹感 | 相邻参考像素间颜色跳变 |
| 只看 ASCII alpha 图验收 | 颜色不均发现不了 | 涂抹感一轮才被用户指出 |
| 文字方案未确认就绘制 | 整轮返工 | FUTURE RACING / 未来竞速 两轮被否决 |
