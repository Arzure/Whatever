# 🎮 游戏中心

万象工坊的实时 3D 游戏模块：每个游戏独立分包按需加载，互不拖累首屏性能。

## 架构总览

```
frontend/src/components/GameView.vue   # 挥剑挑战（首个游戏）
frontend/public/3d/                    # 3D 素材（GLB 模型 + 环境贴图）
```

### 懒加载分包（核心架构决策）
- App.vue 所有视图组件用 `defineAsyncComponent(() => import(...))` 动态引入
- Vite 自动拆分：首屏主包 117K（gzip 44.8K），各视图独立小分包，游戏引擎（Three.js 526K）独立分包
- **新增游戏零成本**：新游戏组件同样懒加载，只有进入该游戏才下载，不影响任何现有页面

### 入口规范
- 首页 3D 世界卡片（`HomeView.vue` 的 `.game-entry`）：宽卡片带 CSS 动效预览，与首页动效语言统一（流光边框/错落入场/hover 提亮/transform 过渡）
- 多游戏时：卡片内加游戏选择列表，或每游戏一张卡片

## 挥剑挑战（Slash Challenge）

### 玩法
- 鼠标快速挥剑切割飞来的多彩方块（全色相随机），漏 3 个结束
- 计分 + 最高分（localStorage `slash-best`）+ 分数弹跳反馈
- 暂停：HUD 按钮 / Esc / P，暂停面板（继续/重开/返回首页），暂停冻结全部障碍物

### 技术要点（踩坑沉淀，新游戏必读）
| 要点 | 说明 |
|---|---|
| 挥砍速度 | 按真实时间间隔计算（归一化坐标/秒），不能用单事件位移×60（恒低于阈值） |
| 碰撞判定 | 剑刃宽面板碰撞盒（薄厚×高×长刃），与视觉剑刃严格对齐；砍中必须同步从数组移除 |
| 相机补偿 | 相机高度 y=1.2 需补偿到跟随映射；活动范围按相机视锥实时计算（tan(fov/2)×距离×aspect） |
| 金属材质 | 高金属度必须配环境贴图（`scene.environment`），否则反射全黑 |
| 拖尾 | WebGL 线宽恒 1 像素；用面状三角带（BufferGeometry + setIndex）实现宽光面 |
| GLB 异步加载 | 加载完成才建模型（开始面板遮住加载期），失败降级几何体兜底 |
| 漏接判定 | 在玩家平面（剑所在 z 略后），视觉与判定一致 |

### 素材
- 剑模型：SlashSaber 开源项目 GLB 三段拼装（blade/guard/hilt + 环境贴图，CC BY 4.0，来源记录于代码注释）
- 素材目录：`frontend/public/3d/sword/`，按需加载不占首屏

## 方块世界（Voxel World）

### 来源与许可
- 完整搬迁自开源项目 [EVEDensity/MineWorld](https://github.com/EVEDensity/MineWorld)（**MIT License**, Copyright (c) 2026 EVEDensity）
- 原项目为无构建步骤的原生 ES Module 项目，整体存放于 `frontend/public/3d/mineworld/`，游戏代码零改动，效果与原版一致
- MIT 要求分发时保留版权与许可声明：LICENSE 文件随代码部署（线上 `/3d/mineworld/LICENSE` 可访问），来源亦注明于 VoxelView.vue 代码注释

### 部署方式
- VoxelView.vue 以 iframe 全屏承载 `/3d/mineworld/index.html`，懒加载分包，进游戏才下载
- Three.js 走原项目自带的 CDN importmap（three@0.160.0），不占用本项目主包
- 游戏内无外部素材依赖：方块纹理、动物、地形全部程序化生成

### 登录保护（2026-10-23 补充）
- `/3d/` 全路径纳入票据 cookie 鉴权：登录用户经 `/api/3d/ticket` 领取短期 HttpOnly cookie（Path=/3d/，2 小时，HMAC 签名），中间件校验，无票据一律 401
- VoxelView 先领票据成功后再挂载 iframe（避免首个请求 401）；挥剑挑战领票据后再加载剑模型，失败走几何剑降级
- 未登录直接访问 `/3d/mineworld/` 等路径返回 401，绕过入口直接玩的路已封死

## 新增游戏指南

1. 新建 `frontend/src/components/XxxGameView.vue`（参考 GameView.vue 的结构：场景构建/游戏循环/输入处理/暂停/清理）
2. App.vue 懒加载引入 + 视图分支（`game.state.view = 'xxx'`）
3. 首页加入口卡片（复用 `.game-entry` 样式语言）
4. 素材放 `frontend/public/3d/`，GLB 异步加载 + 降级兜底
5. 上线流程：改前端 → grep 核实 → `npm run build` → `pm2 restart ai-rpg` → curl 验证新资源 → git 提交推送

## 返回入口规范（2026-10-23 统一）
- 全站视图内不再放置任何返回按钮，统一由顶栏承担：
  - 顶栏『首页』按钮：唯一回首页入口
  - 顶栏『<』按钮：非首页常驻，返回上一级（游戏中心→首页；挥剑挑战/方块世界→游戏中心；文字冒险进行中→模式页；其余→首页）
- 新游戏接入时无需在视图内做返回按钮，顶栏体系自动覆盖
