# ⚔️ 艾泽洛姆 · AI 文字冒险 RPG

> 一个由 AI 实时驱动的文字冒险游戏。输入任意行动，AI 游戏主持人会即时生成剧情、裁决你的行动结果——生命会流逝、金币会增减、命运由你的选择决定。

## ✨ 游戏简介

你是一名初出茅庐的冒险者，踏入中世纪奇幻大陆「艾泽洛姆」。这里有龙、精灵、兽人、远古遗迹与阴谋。**没有预设剧情**——每一次冒险都由 AI 即时生成，你可以：

- 🗡️ 自由输入行动：`"拔出剑警惕地环顾四周"`、`"跟着马蹄印追踪"`、`"尝试与商人讨价还价"`
- 🧭 或点击 AI 推荐选项快速推进
- 📊 实时查看角色状态：生命 / 金币 / 经验升级 / 背包
- 💾 随时退出，下次继续冒险（多存档支持）

## 🚀 快速开始

### 环境要求

- **Node.js ≥ 18**（推荐 20+）
- 一个 **OpenAI 兼容接口**的 API Key（OpenAI / Sensenova / DeepSeek / 国内中转等均可）

### 第一步：配置 AI

1. 复制配置模板：`cp .env.example .env`
2. 编辑 `.env`，填入你的三个 LLM 变量：

```ini
LLM_BASE_URL=https://你的服务地址/v1
LLM_API_KEY=你的密钥
LLM_MODEL=你的模型名
```

> 不知道填什么？默认值分别是 OpenAI 官方地址、`gpt-4o-mini` 模型；使用国产模型服务只需改前两行。

### 第二步：安装依赖

```bash
# 在项目根目录执行，同时安装前后端依赖
npm run install:all
```

### 第三步：启动（需要两个终端）

```bash
# 终端 1 —— 后端（端口 3001）
cd server
npm start

# 终端 2 —— 前端（端口 5173）
cd frontend
npm run dev
```

浏览器打开 **http://localhost:5173**，输入冒险者名字即可开始。

### 关闭

在两个终端分别按 `Ctrl + C` 即可。

## ❓ 常见问题

**Q：页面提示 "AI 处理失败：AI 返回了无法解析的内容"**
A：AI 偶发未按约定格式回复，属正常现象，重试一次即可（你的进度不会丢失）。

**Q：页面提示 "未配置 LLM API"**
A：`.env` 文件缺失或 `LLM_API_KEY` 为空。检查根目录 `.env` 并重启后端。

**Q：修改 `.env` 后不生效？**
A：改完必须重启后端（`Ctrl+C` 后重新 `npm start`），Node 不会自动加载新配置。

**Q：端口被占用（EADDRINUSE）？**
A：说明上次服务未关闭。执行 `lsof -i :3001` 或 `lsof -i :5173` 查看占用进程，`kill <PID>` 后重启。

**Q：可以多人同时玩吗？**
A：目前是单人游戏，存档以 JSON 文件保存在本地 `data/` 目录。

## 🛠️ 技术栈与结构

| 层 | 技术 |
|----|------|
| 前端 | Vue 3 + Vite 6（暗色奇幻风 UI） |
