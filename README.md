# 🎲 AI 文字冒险 RPG

> 一个由 AI 实时驱动的多模式文字冒险游戏。输入任意行动，AI 游戏主持人即时生成剧情、裁决结果——生命会流逝、金币会增减、真相会被揭开，命运由你的选择决定。

## ✨ 游戏模式

游戏采用**可插拔模式（Mode）+ 世界观配置（Theme）**架构，同一套引擎适配任意题材：

| 模式 | 状态 | 说明 |
|------|------|------|
| 🗺️ **大世界模式** | ✅ 已实现 | 自由探索型冒险：输入任意行动推进剧情，AI 即时生成结果，无限延伸 |
| 🔍 **探案模式** | ✅ 已实现 | 有明确胜利条件的推理模式：AI 设计案件，收集线索与物证、用物证拆穿说谎者、指认并让凶手认罪 |
| 🐺 **狼人杀模式** | ✅ 已实现 | 单人 5 人局推理狼人杀：玩家固定村民，AI 扮演狼人/预言家/村民，白天发言博弈、投票放逐 |

### 🗺️ 大世界模式

**没有预设剧情**——每一次冒险都由 AI 即时生成，你可以：

- 🗡️ 自由输入行动：`"拔出剑警惕地环顾四周"`、`"跟着马蹄印追踪"`、`"尝试与商人讨价还价"`
- 🧭 或点击 AI 推荐选项快速推进
- 📊 实时查看角色状态：生命 / 金币 / 经验升级 / 装备 / 背包
- 💾 随时退出，下次继续冒险（多存档支持）

### 🌍 自定义世界观（任意题材）

世界观不再是写死的。你可以：

- 从内置世界中选择（默认模板 **艾泽洛姆**——中世纪奇幻大陆）
- 或**粘贴一段纯文本世界观**，由 AI 自动结构化为可玩的配置

AI 会从文本中识别出**这个世界是否需要战斗、是否有武器/防具、有哪些数值与物品**：

- 有战斗的中世纪奇幻 → 生命 / 金币 / 经验 + 武器槽 + 防具槽 + 背包
- 无需战斗的现代都市 / 解谜 / 经营 → 仅生命（或更少）+ 背包，**不出现武器与防具**

> 举例：粘贴「2024 年的海滨城市雾港，没有魔法也没有战斗，人们靠推理与对话解决问题」→ AI 会生成一个无战斗、无装备的世界，叙事风格随之改变。

### 🔍 探案模式

**成功条件：让凶手认罪。** 案件由 AI 即时生成（先选题材，支持 现代都市 / 古代衙门 / 民国旧案 / 奇幻王国 / **蒸汽时代**），你需要在限定场景内调查：

- 🕵️ 自由探索场景与在场人物，通过对话收集**线索**（存入背包）
- 🔬 找到**物证**（如监控/门禁/指纹记录），装备到物证槽——不同物证能拆穿不同说谎者，**也能拆穿凶手部分谎话**（凶手被击破后只会部分坦言、不会直接自证）
- 🤥 有些 NPC 会**说谎**提供假线索：出示能反驳他的物证当面质问，他就会改口说出真相并交代撒谎原因
- ⚖️ **随时可指认凶手**，认错会损失生命（每次 -25）——生命归零则调查终止，真凶逍遥法外
- ⚔️ 指认正确后进入**对质**：勾选关键线索一举举证，覆盖度足够凶手认罪即胜利；举证失败不扣生命、线索不丢失（可继续调查）
- 📁 案件说明默认保密，展开前有剧透提醒；真相由代码持有，AI 只负责演绎，不漂移。展开后可见凶手/说谎者标签、撒谎动机、口供真伪与关键证据清单
- 🧭 诚实 NPC 坦然配合，盘问已问尽的人/搜遍的场景会得到明确提示，避免无意义探索
- 🚶 场景移动支持文字通道：输入「前往物业前台」（可省略公共前缀用简称）或直接点场景按钮，程序判定移动、状态与叙事保持一致

### 🐺 狼人杀模式

**成功条件：投票放逐所有狼人。** 单人 5 人局（你 + AI 玩家），你固定扮演**村民**，找出潜伏的狼人：

- 🌙 夜晚由程序结算：狼人刀人、预言家验人，天亮直接公布死讯（被刀者身份不公开）
- 🗣️ 白天自由发言：你先发言，4 名 AI 依次回应——狼人会伪装辩解、预言家可公布验人结果、村民凭逻辑怀疑
- 🗳️ 投票放逐：投票放逐最可疑的人，**被放逐者身份公开**；放逐狼人即好人获胜
- 🏆 胜负：狼人被放逐 → 好人胜；你死亡或好人阵营仅剩你 → 狼人胜。游戏结束会揭示全部身份复盘
- 🔒 身份真相由代码持有，AI 只按身份发言，绝不剧透

## 🚀 快速开始

### 环境要求

- **Node.js ≥ 18**（推荐 20+）
- 一个 **OpenAI 兼容接口**的 API Key（OpenAI / Sensenova / DeepSeek / 国内中转等均可）

### 第一步：配置 AI

1. 复制配置模板：`cp .env.example .env`
2. 编辑 `.env`，填入你的三个 LLM 变量：

```ini
LLM_BASE_URL=https://你的服务地址/v1
LLM_API_KEY=你的密钥
LLM_MODEL=你的模型名
```

> 不知道填什么？默认值分别是 OpenAI 官方地址、`gpt-4o-mini` 模型；使用国产模型服务只需改前两行。

### 第二步：安装依赖

```bash
# 在项目根目录执行，同时安装前后端依赖
npm run install:all
```

### 第三步：启动（需要两个终端）

```bash
# 终端 1 —— 后端（端口 3001）
cd server
npm start

# 终端 2 —— 前端（端口 5173）
cd frontend
npm run dev
```

浏览器打开 **http://localhost:5173**，选择模式与世界、输入名字即可开始。

### 关闭

在两个终端分别按 `Ctrl + C` 即可。

## 🎮 玩法提示

| 技巧 | 说明 |
|------|------|
| 自由行动 | 输入框不限固定命令，AI 会理解自然语言并给出合理结果 |
| 战斗 | 遇敌时输入攻击/防御/逃跑等指令，界面会显示"⚔️ 战斗中"标识（仅启用战斗的世界观） |

| 待结算动作 | 按钮操作会先进入「待结算动作」条，提交行动前可点 ✕ 撤销 |

## ❓ 常见问题

**Q：页面提示 "AI 处理失败：AI 返回了无法解析的内容"**
A：AI 偶发未按约定格式回复，属正常现象，重试一次即可（你的进度不会丢失）。

**Q：页面提示 "未配置 LLM API"**
A：`.env` 文件缺失或 `LLM_API_KEY` 为空。检查根目录 `.env` 并重启后端。

**Q：修改 `.env` 后不生效？**
A：改完必须重启后端（`Ctrl+C` 后重新 `npm start`），Node 不会自动加载新配置。

**Q：端口被占用（EADDRINUSE）？**
A：说明上次服务未关闭。执行 `lsof -i :3001` 或 `lsof -i :5173` 查看占用进程，`kill <PID>` 后重启。

**Q：导入自定义世界观失败？**
A：需要后端已配置 LLM；若提示解析失败，可调整文本让它更明确（如说明"是否有战斗""用什么货币"），或重试一次。

**Q：可以多人同时玩吗？**
A：目前是单人游戏，存档以 JSON 文件保存在本地 `data/` 目录。

## 🛠️ 技术栈与结构

| 层 | 技术 |
|----|------|
| 前端 | Vue 3 + Vite 6（暗色奇幻风 UI） |
| 后端 | Node.js + Express 4 |
| AI | OpenAI 兼容 `/chat/completions`（零 SDK，内置 fetch） |
| 存储 | JSON 文件（`data/` 目录） |

```
Whatever/
├── .env.example          # 配置模板（复制为 .env 后填写）
├── server/               # 后端
│   ├── engine.js         # 引擎共享层（解析/重试/降级/物品操作）
│   ├── modes/            # 游戏模式（world：大世界模式 / detective：探案模式）
│   ├── themes/           # 世界观配置（azeroth.json + 文本解析）
│   └── ...

├── data/                 # 游戏存档（运行时生成）
```
