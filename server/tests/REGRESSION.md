## 历史教训（新增检查项时参考）

- 渐变透明文字（background-clip:text）渲染不可靠——标题用实心纯色
- v-if 区块内插新元素会破坏 v-else 配对——插入前检查同级关系
- 动画时长硬编码与文字时序耦合——改动画必须核对相关延迟
- cover 裁切会吃掉图片上下各 20%——叠放元素要放在可见带内
